# Customer Churn & Revenue Impact Analysis

### Project Overview
An end-to-end data analytics project focused on analyzing customer churn, subscription behavior, and revenue impact for an OTT subscription platform.
The project integrates multiple relational datasets, analyzes 20+ KPIs, identifies churn patterns, and develops data-driven strategies to improve customer retention and revenue.

### Tools & Technologies

1. NumPy & Pandas: Data cleaning and preprocessing
2. Matplotlib & Seaborn: Data Visualization
3. SQL: Data extraction and table integration
4. SQLite: Database management
5.Jupyter Notebook: Analysis and documentation

Churn Rate     : 28.6%

Annual Churn   : 8.3%

Revenue Loss   : 74
Revenue Loss % : 18%
CLTV Lost      : 2,047

### Key Findings
1. Monthly subscribers experienced approximately 6.7x higher churn than annual subscribers.
2. The highest cancellation activity occurred in September 2024.
3. Karnataka recorded the highest customer churn.
4. Escalated customer support interactions were disproportionately concentrated among churned customers.
5. Customer risk segmentation highlighted opportunities for targeted retention strategies.

###  Business Recommendations

1. Encourage monthly subscribers to migrate toward annual plans.
2. Investigate regional churn patterns and pricing-related issues.
3. Prioritize high-value customers with elevated churn risk.
4. Improve customer support and complaint resolution.
5. Develop retention strategies based on Customer Lifetime Value (CLTV).
